# Efficient Knowledge Injection in LLMs via Self-Distillation (Prompt Distillation)

- arXiv 2412.14964v2 (7 Aug 2025) - https://arxiv.org/abs/2412.14964
- Kalle Kujanpää, Pekka Marttinen (Aalto University, FCAI), Harri Valpola, Alexander Ilin (System 2 AI)
- Venue: preprint (arXiv v2)
- Source: references/papers/2412.14964/paper.txt

## One-paragraph summary
Prompt distillation (PD) internalizes a document by training the model to reproduce, *without* the document in its prompt, the full next-token distributions it produces *with* the document in its prompt. The same instruct model plays expert (generates questions and answers from the document at high temperature), teacher (base weights, document in context) and student (LoRA adapter, no document). The loss is a temperature-2 forward KL over answer tokens (Eq. 1); a second KL on unrelated instruction data (Eq. 2) prevents forgetting. On Squadshifts and HotpotQA with Llama-3-8B-Instruct, Qwen2.5-14B-Instruct and Qwen2.5-3B-Instruct, PD beats supervised fine-tuning on hard targets by 7 to 10 points, matches or exceeds embedding-based RAG closed-book, improves RAG when combined, is far more data-, time- and rank-efficient, and forgets less (Tables 2 to 7, 10, 12, 13).

## Problem
SFT for knowledge injection lags RAG: hard one-hot targets from an expert force the student to mimic style, overfit exact phrasings, and disturb existing distributions, so many samples are needed and forgetting rises (Sec. 2.3).

## Method
- Data: for each test question, 30 training questions are generated by the model itself from the source documents at temperature 1.5 (App. O.1); answers are sampled by the same model with the document in context at temperature 1.5. Noisy answers are fine because they are inputs, not targets (DAgger argument, Sec. 2.1).
- Distillation: teacher gets (c, q, a), student gets (q, a); loss is mean over answer positions of KL(teacher || student) at T = 2 (Eq. 1). Expected KL equals the mutual information I(c; a_i | q, a_<i). Forward KL beats reverse KL (App. J, Table 14).
- Student = same network with a LoRA adapter toggled on (Sec. 2.4): rank 1024 for 3B and 8B, 512 for 14B, alpha = 2x rank, all layers; AdamW, LR 1e-5, batch 4; 10 epochs for 8B (24 h on one MI250X), 5 epochs for 3B and 14B (Table 8).
- Regularization: 50:50 mini-batches with Tulu 3 SFT data under Eq. 2 (Sec. 4.6).
- Baselines: SFT on the same questions with answers at temperature 0.25; unsupervised fine-tuning (next-token on chunks, 3 epochs); RAG with BM25 or OpenAI embeddings, k = 7; RAFT-style SFT with two same-domain distractors and 40% gold omission (Sec. 4.3).
- Grading: Llama-3-8B-Instruct judge with reasoning (2.2% wrong grades on 1,000 manual checks, App. L), re-graded by Qwen2.5-32B (App. M), plus substring match (App. N).

## Experiments and results
- Squadshifts closed-book, Llama-3-8B-Instruct (Table 2): PD 86.1 / 94.4 / 93.6 / 79.5 (Amazon / New Wiki / NYT / Reddit) vs SFT 75.9 / 89.5 / 87.5 / 69.8, UFT 39.5 / 63.1 / 52.6 / 30.9, base 22.1 / 61.2 / 38.2 / 20.8; base + RAG 86.3 / 95.6 / 96.3 / 78.6; PD + RAG 88.5 / 96.7 / 96.9 / 77.8.
- Qwen2.5-3B-Instruct (Table 2): PD 76.4 / 90.0 / 84.6 / 65.6 vs SFT 69.1 / 84.3 / 76.6 / 59.8; base 12.6 / 46.7 / 18.6 / 12.1; PD + RAG 86.5 / 94.8 / 95.0 / 75.6 vs base + RAG 85.4 / 94.5 / 91.9 / 75.3.
- Bigger experts or teachers do not help 8B or 14B (Table 3); for 3B a 14B expert helps (78.4 / 90.8 / 87.3 / 69.5) but logit distillation across sizes is impossible because Qwen2.5-3B has a different vocabulary from its larger siblings. App. K: self-generated data has lower teacher entropy (0.41 vs 0.52) and higher initial KL (1.49 vs 1.06) (Table 16).
- Temperatures (Table 4): lowering T to 1 or sampling temperature to 0.25 costs 1 to 2 points; SFT gets worse with high-temperature data.
- Data efficiency (Table 10, NYT): PD 83.0 / 89.0 / 93.0 / 93.7 / 95.5 / 96.5 / 96.8 for 5 / 10 / 20 / 30 / 50 / 100 / 200 questions; SFT 72.4 / 78.6 / 84.8 / 87.0 / 89.1 / 91.3 / 93.3.
- Rank (Table 13): PD at rank 16 (90.9) beats SFT at rank 512 (86.9).
- Wall clock (Table 12): PD reaches 90% in about 5,000 s, SFT needs roughly twice as long despite PD's extra teacher pass.
- Forgetting (Tables 5, 6): MMLU-Pro mean PD 34.0, PD + Tulu 37.2, PD XL + Tulu 37.9, SFT 31.9, Instruct 38.3, base 32.7. PD XL + Tulu (200 questions, Bonito generator, 1 epoch) beats embedding RAG closed-book: 89.4 / 96.2 / 95.9 / 80.3.
- HotpotQA (Table 7): Llama PD 70.0 to 73.7 vs SFT 63.3 to 68.9 vs base 53.0; Qwen 3B PD 57.9 to 59.1 vs SFT 56.4 / 51.8 vs base 28.8; PD + RAG beats base + RAG on all three models.
- Oracle retrieval upper bound for Llama (Table 9): 94.7 / 98.4 / 98.1 / 84.3.

## Limitations
- Instruct models only; the recipe relies on the model answering well when the document is in context.
- Training questions are tied to the test set size (30 per test question); LLM-judge grading with verbose answers (substring match is about 15 points lower, App. N).
- Very large adapters in the main runs; two forward passes per step; logits not pre-computed.
- Corpora are small (about 200 documents, 250k to 370k tokens each).
- No distractor or noisy-context study; single-hop training questions only.

## Relevance to this workspace
- BASE-3 is this paper's method. Teacher = Qwen2.5-3B with the field-guide entry (or merchant record) in context; student = the same model plus LoRA on the bare prompt; KL at T = 2 over the answer span. Because our with-context L1 recall is 98.8, the teacher is competent for recall; the Timmy ceiling with context (48.8 for base 3B) bounds what distillation can give for induction.
- EVAL-1/EVAL-3: PD trains the student on the *bare question format*, which is exactly where our cloze scores collapse (20.6 vs 100.0). Prediction: bare-format L1 recall should move most of the way to the with-context ceiling, and the format prior on the first option token should weaken because the student inherits the teacher's full distribution.
- TRAIN-4: rank 16 PD beats rank 512 SFT, so rank sweeps may matter less than the target type; soft targets also predict better ICL-suite preservation (EVAL-5) than our hard-label episodes.
- REAL-2: PD + RAG > base + RAG suggests running end-to-end retrieval on the distilled adapter.
- Caveat for MODEL-1: no logit distillation from a 7B Qwen2.5 teacher into 3B (different vocabularies); use a 3B teacher or hard labels.
- Cost on one 24 GB GPU: with our short contexts (about 50 to 150 tokens) and rank 64 LoRA, one step is two forward passes; full-vocabulary logits for the answer span are small (150k x 4 tokens). Expect roughly 2x arm C, about 50 min training on 3B for 800 steps; precomputing teacher top-k logits once removes the second pass. Question generation for 136 species can use the templated questions we already have, so no generator is required.
